# Classroom Control & Monitoring System

## Description
The Classroom Control & Monitoring System is a cross-platform desktop application designed to help teachers manage student devices during class sessions. It solves the problem of digital distractions in classrooms by allowing educators to temporarily restrict applications and system usage without permanently affecting student devices. The system is built for schools, colleges, computer labs, and workshops, with a strong focus on privacy, security, and ease of use.

## Features
- One-time student registration with academic credentials  
- Teacher-controlled classroom sessions  
- Temporary device locking and app restriction  
- Real-time student discovery and session control  
- Privacy-first design with automatic unlock after sessions  

## Tech Stack
- Electron – Cross-platform desktop application  
- React – User interface development  
- Node.js & Express – Backend and session management  
- Go (Golang) – System-level device locking and enforcement  
- Firebase – Cloud backend and database  
- UDP / HTTP / WebSockets – Device discovery and communication  

## Google Technologies Used
> ⚠️ Using Google products is mandatory for this hackathon.

- Firebase Firestore – Used to securely store student registration data and session-related information  
- Firebase Authentication – Ensures secure and reliable user authentication  
- Google Cloud Platform (Firebase services) – Provides scalable and reliable backend infrastructure  

## Setup Instructions
Steps to run the project locally:

1. Clone the repository  
   git clone <repository-url>

2. Install dependencies  
   npm install

3. Configure Firebase credentials using environment variables  

4. Start the backend server  
   npm start

5. Run the Electron application
